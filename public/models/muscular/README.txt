ANATOMY 3D — ASSET REPOSITORY

Place your Z-Anatomy or custom GLB model at:
public/models/muscular/muscular.glb

The application automatically loads muscular.glb on launch.
If no file is present at this path, the application seamlessly uses its high-precision built-in 3D anatomical muscle rig.
Users can also drag & drop or upload GLB/GLTF assets at runtime via Atlas Settings -> Import Custom GLB Asset.
